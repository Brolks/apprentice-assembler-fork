# Apprentice assembler (Fork)

[![](https://img.shields.io/badge/github-fork_source-white?logo=github)](https://github.com/Quezler/glutenfree/tree/main/mods_2.0/057_apprentice-assembler)

I found this mod and really liked the concept and visuals, but the original is no longer actively maintained.
So I made and maintain this updated fork for Factorio 2.0 with current dependency compatibility.

## What this machine does

It keeps a similar core identity to assembling machine 3, but gains internal speed boost through continuous crafting.
The boost grows by 1% per completed craft and decays while idle.

## Current fork behavior

- Default module slots were reduced from 4 to 1 for balance.
- You can set your preferred module slot count in startup settings.
- Crafting speed bonus still scales with quality and can be boosted further by beacons/modules.
- Logic is lightweight: runtime script activity is focused on ramp-up and stop events.

## Why this fork exists

- Keep a great concept alive for 2.0 users.
- Fix outdated integration with beacon-interface.
- Provide configurable balance and clearer behavior.
